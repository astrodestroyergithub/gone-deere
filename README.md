## Quick Deploy to Netlify
1. **Drag & Drop**: Unzip `gone-deere-netlify.zip` and drag the folder directly into [Netlify Drop](https://app.netlify.com/drop).
2. **Git / CLI Deploy**:
   ```bash
   netlify deploy --prod --dir=.
   ```
